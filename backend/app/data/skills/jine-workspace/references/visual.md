# 界面与阅读排版

- 沿用 JINE 像素风的结构、边线和交互位置。阅读正文优先保证对比、换行、扫描、键盘焦点与日语断行。可以增加字号与行距，保留足够内容宽度。长文适用可调字号、行距、行宽、字体和亮暗主题。
- `reading.style` 只传用户指定字段。`size` 为 14–26，`line_height` 为 1.35–2.25，`measure` 为 44–90，`font` 为 `serif` 或 `sans`，`theme` 为 `lilac`、`paper` 或 `night`。需要更大结构调整时给出文件和预期行为。
- 功能增长时保留稳定的主导航，学习与复习分别在各自的子页面。入口用短动词或明确图标，展开后再展示精细选项。错题本保留答案证据的位置，读论文保留页码和选段。
- 界面源文件在 `frontend/index.html`、`frontend/js/app.js`、各功能的 JS 与 CSS。以桌面和窄窗口各一例验证菜单、焦点、阅读和从任意页面返回，检查正文与面板间互相遮挡。
