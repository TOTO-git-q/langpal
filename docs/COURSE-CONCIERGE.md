# 课程管家与课程预览

课程按学习语言保存。聊天、听力、阅读、设置和课程管家共用 `teaching_language:<tag>`，
不把课程挂到管家会话或角色上。`mode=ambient` 表示这门语言的课程在用。
进度怎么算、一课怎么上、证据从哪来，见 `COURSE-KERNEL.md`；这份文档只讲选课、预览和课程管家。

- 选择课程后直接保存，下一条消息使用。可以暂停，再继续。
- 设置 `teaching_evaluator`（默认 `auto`：辅助引擎是 DeepSeek 时才开）只管"闲聊时也评"。
  上课时的评价总是做；阅读题、听力题的证据不用模型。
- 设置的「课程与世界书」显示可直接编辑的预览。编辑预制课程会保存为自制版本。
- 制作大纲、阅读教材、批量调整和连接来源在课程管家的对话中完成。
  管家产生的更改在对话内确认，仍沿用已有的冲突检查、应用和撤销机制。
- 备考课（一课练一种题型的分项课，比如托福那门）不在这里手编。要一门新的（四六级、雅思、高考、N1……），在管家的对话里说
  「帮我做一门六级的课」：管家的回答下面出现「开始做这门课」，点了之后后台照托福那门课的做法一课一课做出来，
  进度、接着做、重做、删掉都在设置的课程页。做法、数据文件和检查见 `COURSE-KERNEL.md` 第 14 节。
  做出来的课在数据目录的 `lessons/<id>/`（id 以 `my-` 开头），和自带的课排在同一个目录里选。
- 下面说的「自制课程」是另一种：聊天里顺带学的大纲（version 2）。
- 自制课程保存在 `teaching_saved_outline:<language>:<id>`。
  切换当前课程会保留它；相同 ID 的编辑更新该课程的最新版本。
  `/api/teaching/presets` 合并内置课程和标记 `custom:true` 的已保存课程。
  这个标记只用于目录展示，提交大纲时去掉。含有私人内容的目录采用同源检查。

听力安排保存在 `listening_plan:<tag>`，与课程相互独立：题型、材料难度和主题可以直接编辑，
也可通过课程管家 `listening.plan` 工具调整。音色和语速继续走 `voice.listening`。
选择「跟随课程」时，出题围绕课程里听力这条线现在该碰的知识点，题目可以标上知识点，交卷后记进课程的账；
主动选择基础、进阶或挑战时，使用用户选定的材料难度，不带课程。
没有启用课程时保留已有默认练习。以上不构成能力测评。

`POST /api/listening/plans/{language}` 接收 `{format, difficulty, topic}`。
`GET /api/listening/options` 返回各语言的 `plans`，题型仍来自现有格式注册表。
新功能可复用课程管家的工具注册表、技能参考和变更审阅，无需在界面再建一个工具工作台。
